CATE with the frugal (copula) model

This vignette fuses a trial with one observational data set to estimate a CATE, using the frugal parametrisation from causl.

The four blocks

Let \(C\) be baseline covariates (including effect modifiers), \(Z\) further pre-treatment variables, \(X\) the treatment and \(Y\) the outcome. The frugal factorisation is

\[p(c)\;p(z\mid c)\;p(x\mid z,c)\;q(y\mid do(x),c), \quad\text{with a copula linking } z \text{ and } y.\]

The outcome margin \(q(y\mid do(x),c)\) is the law of \(Y\) under an intervention on \(X\); its coefficients are the causal effect. For MDPL you supply three of the four blocks as one flat list of formulas:

block models what to put in it
1. Z pre-treatment variables \(p(z\mid c)\) one formula per variable, e.g. Z ~ C1. Nuisance: keep it simple.
2. X treatment and covariate margins used to generate data only; left out of the fit.
3. Y the causal margin \(q(y\mid do(x),c)\) the causal block. X, interacted with each modifier the CATE depends on (Y ~ X * C1). No Z here.
4. cop dependence between the margins a one-sided formula (~ 1, ~ X * C1). Nuisance, but it does the adjustment for \(Z\).

So the specification is

spec <- mdpl_causl(
  formulas = list(
    Z ~ C1,        # block 1
    Y ~ X * C1,    # block 3: CATE terms Y:X and Y:C1:X
    ~ X * C1       # block 4
  ),
  family = c(1, 1, 1),
  outcome = "Y",
  kwd = "cop"
)
spec
#> <mdpl_spec> causl frugal model, margins: Z, Y

and the CATE is the outcome margin’s linear predictor at \(X=1\) minus \(X=0\), \(\tau(c_1)=\beta_X+\beta_{X:C_1}c_1\). Only the outcome block enters it; the Z and copula blocks sharpen and de-bias those two coefficients. family is one code per formula (1 Gaussian, 5 binary; the last is the copula).

A simulated example

The trial (\(n_e=250\)) is randomised. The observational data (\(n_o=1000\)) are confounded by a binary \(U\) that affects both treatment and outcome and is dropped before analysis. The true CATE is \(\tau(c_1)=0.8+0.3c_1\). The generator needs all four blocks, including a treatment model.

set.seed(11)
n_e <- 250; n_o <- 1000
family <- list(1, c(5, 1, 5), 1, 1)   # families for blocks Z, (X, C1, U), Y, copula

forms_obs <- list(
  Z ~ C1,
  list(X ~ Z * C1 + U, C1 ~ 1, U ~ 1),
  Y ~ X * C1 + U,
  ~ X * C1
)
forms_exp <- forms_obs
forms_exp[[2]][[1]] <- X ~ 1                      # randomised

pars_obs <- list(
  C1 = list(beta = 0, phi = 1),
  U = list(beta = 0),
  Z = list(beta = c(0.2, 0.6), phi = 1),
  X = list(beta = c(0.5, 0.6, 0.1, 1, 0.4)),       # U drives treatment
  Y = list(beta = c(0.6, 0.8, 0.2, 1, 0.3), phi = 2),
  cop = list(beta = matrix(c(1, 2.5, 0, 0), nrow = 4))
)
pars_exp <- pars_obs; pars_exp$X <- list(beta = 0)

d_o <- causl::rfrugalParam(
  n = n_o,
  formulas = forms_obs,
  family = family,
  pars = pars_obs
)
#> Inversion method selected: using pair-copula parameterization
d_e <- causl::rfrugalParam(
  n = n_e,
  formulas = forms_exp,
  family = family,
  pars = pars_exp
)
#> Inversion method selected: using pair-copula parameterization
d_o$U <- d_e$U <- NULL                            # U is not observed

Y:X and Y:C1:X are \(\beta_X\) and \(\beta_{X:C_1}\) (truth 0.8 and 0.3). The rest (Z:*, cop*, phi:*) is nuisance. The weight is judged on all parameters by default; target = "cate" judges it on the two treatment-effect parameters only.

CATE and ATE

The table compares three estimates of the CATE at \(C_1=-1,0,1\): the trial alone (fit$rct), MDPL, and a pooled fit that takes the observational data at full weight (eta = 1). mdpl_cate() returns the estimate, standard error and interval for each, and truth is the known \(0.8+0.3c_1\).

g <- data.frame(C1 = c(-1, 0, 1))
pooled <- mdpl_posterior(fit$fit_exp, fit$fit_obs, eta = 1, treat = "X")   # eta = 1
tab <- rbind(
  cbind(method = "trial only", mdpl_cate(fit$rct, g, treat = "X")),
  cbind(method = "MDPL",       mdpl_cate(fit, g)),
  cbind(method = "pooled",     mdpl_cate(pooled, g)))
tab$truth <- 0.8 + 0.3 * tab$C1

The ATE averages the CATE over the covariates of a data frame (by default the trial’s). The code below gives it for the same three methods, then prints the true value over the trial covariates for comparison:

rbind(`trial only` = mdpl_ate(fit$rct, d_e, treat = "X"),
      MDPL = mdpl_ate(fit),
      pooled = mdpl_ate(pooled, d_e))
#>             estimate         se     lower     upper
#> trial only 0.6166186 0.14546189 0.3315186 0.9017187
#> MDPL       0.7927712 0.09965934 0.5974425 0.9880999
#> pooled     0.8511149 0.07804098 0.6981574 1.0040724
cat("true ATE over the trial covariates:", round(0.8 + 0.3 * mean(d_e$C1), 3), "\n")
#> true ATE over the trial covariates: 0.793

Pooling (eta = 1) takes the observational estimates at face value; MDPL borrows only as much as the trial supports. The bootstrap (bootstrap_CI = TRUE, see the intervals vignette) refits both models per replicate, which with causl is slow.

Note: if you have several observational data sets, pass a list of data frames; each gets its own weight and is fitted separately.

Also, target = "cate" picks up every outcome-block coefficient involving X, including further modifiers.
