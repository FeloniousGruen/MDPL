Intervals for MDPL estimates: posterior and bootstrap

Two kinds of interval

mdpl_cate(), mdpl_ate() and mdpl_coef() return one of two kinds of interval.

  • Posterior (the default for a plain fit): the normal power posterior given the selected weights. It is instant.
  • Bootstrap (bootstrap_CI = TRUE): resample the data, refit every model, reselect the weights and recompute the effect. It costs about B fits.

The weights are chosen from the trial data, but the posterior treats them as fixed. The two can be close when a source is clearly clean or clearly useless, since the weight is then stable. They often paritcularly differ when a source is only moderately informative and the weight varies from trial to trial.

sim <- function(n, bias = 0) {
  X <- rnorm(n, 1); U <- rnorm(n)
  A <- rbinom(n, 1, if (bias == 0) 0.5 else plogis(X - 1 + bias * U))
  data.frame(X = X, A = A, Y = 0.5 + X + 0.2 * A + 0.1 * A * X + bias * U + rnorm(n))
}
set.seed(11)
trial <- sim(300); obs <- list(src = sim(1000, 0.5))   # moderately confounded
nd <- data.frame(X = c(0, 1, 2))                       # truth: 0.2 + 0.1 X

It is an argument of the fitting call, off by default.

Once replicates are stored, the effect functions and the stored coefficients and ATE (fit$estimates) use them. The stored CATE formula uses the posterior; call mdpl_cate() for bootstrap intervals at covariate values. Choose the kind with ci:

post <- mdpl_cate(fit, nd, ci = "posterior")
boot <- mdpl_cate(fit, nd)               # ci = "auto" -> bootstrap
data.frame(X = nd$X, estimate = boot$estimate,
           post_width = post$upper - post$lower,
           boot_width = boot$upper - boot$lower)
#>   X  estimate post_width boot_width
#> 1 0 0.2775113  0.5760822  0.4460388
#> 2 1 0.3249944  0.4045596  0.4656602
#> 3 2 0.3724774  0.5939560  0.6642701

The point estimate is the same; the bootstrap se is the standard deviation of the replicates. Percentile endpoints generally need more replicates (100 here to build quickly). With fewer, interval = "normal" (estimate \(\pm\) 1.96 bootstrap standard errors) can be steadier:

mdpl_cate(fit, nd, interval = "normal")
#>   X  estimate        se       lower     upper
#> 1 0 0.2775113 0.1391305 0.004820459 0.5502021
#> 2 1 0.3249944 0.1187320 0.092283836 0.5577049
#> 3 2 0.3724774 0.1743261 0.030804503 0.7141504

For a fit made without the bootstrap, mdpl_cate_boot(), mdpl_ate_boot() and mdpl_coef_boot() run one on demand (B = 500 by default).

What is stored

fit$boot$draws is a B x p x traces array of the fused parameters across replicates (traces t1 and t2, default t2). Any function of the parameters can be summarised from it:

dr <- fit$boot$draws[, c("A", "A:X"), "t2"]
head(round(dr, 2), 3)
#>         A  A:X
#> [1,] 0.29 0.19
#> [2,] 0.20 0.08
#> [3,] 0.35 0.12
hist(dr[, "A"] + 1 * dr[, "A:X"], breaks = 25, main = "",
     xlab = "bootstrap CATE at X = 1")
abline(v = 0.3, lty = 2)

The spread includes the weight changing between replicates, which the posterior interval, with its fixed weight, cannot see.

Effects that are not linear in the parameters

With a non-identity link the response-scale effect (the risk difference for a logistic model) is nonlinear in the parameters. The bootstrap maps each replicate through the effect; the posterior route uses normal posterior draws.

simb <- function(n, bias = 0) {
  X <- rnorm(n); U <- rnorm(n)
  A <- if (bias == 0) rbinom(n, 1, 0.5) else rbinom(n, 1, plogis(X + bias * U))
  data.frame(X = X, A = A,
             Y = rbinom(n, 1, plogis(-0.3 + 0.8 * A + 0.5 * X + 0.3 * A * X + bias * U)))
}
set.seed(12)
fb <- mdpl(Y ~ A * X, simb(500), list(simb(1500, 1)), treat = "A", family = binomial(),
           bootstrap_CI = TRUE, B = 100, boot_seed = 1)
nd2 <- data.frame(X = c(-1, 0, 1))
mdpl_cate(fb, nd2)                       # risk difference, bootstrap
#>    X   estimate         se      lower     upper
#> 1 -1 0.05919177 0.07336847 -0.1170648 0.1847551
#> 2  0 0.24373586 0.03968275  0.1837193 0.3120702
#> 3  1 0.35208616 0.04667146  0.2686762 0.4367298
mdpl_cate(fb, nd2, ci = "posterior")     # risk difference, posterior
#>    X   estimate         se       lower     upper
#> 1 -1 0.05919177 0.06051173 -0.05811877 0.1818476
#> 2  0 0.24373586 0.04193455  0.15867126 0.3244104
#> 3  1 0.35208616 0.05085089  0.24717803 0.4461980
mdpl_ate(fb)
#>    estimate         se     lower     upper
#> 1 0.2150044 0.03807161 0.1475373 0.2922894

What the ATE is averaged over

mdpl_ate() averages the CATE over the covariates of a data frame, by default the trial’s, held fixed in every replicate. Pass another population’s covariates as data:

mdpl_ate(fit, data = data.frame(X = c(1.5, 2, 2.5)))
#>    estimate        se        lower     upper
#> 1 0.3724774 0.1743261 -0.009846219 0.6544239

Note on interval choice

Posterior intervals can be useful for exploration but bootstrap intervals more fully account for the true uncertainty of the method. A bootstrap interval much wider than the posterior one suggests unstable weights.
